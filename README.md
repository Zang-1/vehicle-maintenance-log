# Vehicle Maintenance Log

A web app for tracking vehicle maintenance history and getting AI-suggested diagnoses for unusual symptoms.

## What it does
- Track vehicles and their maintenance records (date, category, cost).
- Enter a free-text symptom description (e.g. "brakes squeaking") and get an AI-suggested likely cause and urgency level.
